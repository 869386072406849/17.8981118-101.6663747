<h1 class="wp-block-heading has-text-align-center alignwide">Web browser</h1>
<!-- /wp:heading -->

<!-- wp:paragraph {"style":{"typography":{"textAlign":"center"}}} -->
<p class="has-text-align-center">Software used to access websites</p>
<!-- /wp:paragraph -->

<!-- wp:separator -->
<hr class="wp-block-separator has-alpha-channel-opacity" />
<!-- /wp:separator -->

<!-- wp:paragraph -->
<p><a href="https://en.wikipedia.org/w/index.php?title=Web_browser&amp;action=edit&amp;section=0"></a></p>
<!-- /wp:paragraph -->

<!-- wp:paragraph -->
<p>A <strong>web browser</strong>, often abbreviated as <strong>browser</strong>, is an <a href="https://en.wikipedia.org/wiki/Application_software">application</a> for accessing <a href="https://en.wikipedia.org/wiki/Website">websites</a>. When a <a href="https://en.wikipedia.org/wiki/User_(computing)">user</a> requests a <a href="https://en.wikipedia.org/wiki/Web_page">web page</a> from a particular website, the browser retrieves its <a href="https://en.wikipedia.org/wiki/Computer_file">files</a> from a <a href="https://en.wikipedia.org/wiki/Web_server">web server</a> and then displays the page on the user's screen. Browsers can also display content stored locally on the user's device.</p>
<!-- /wp:paragraph -->

<!-- /wp:image -->

<!-- wp:paragraph -->
<p>Browsers are used on a range of devices, including <a href="https://en.wikipedia.org/wiki/Desktop_computer">desktops</a>, <a href="https://en.wikipedia.org/wiki/Laptop">laptops</a>, <a href="https://en.wikipedia.org/wiki/Tablet_computer">tablets</a>, <a href="https://en.wikipedia.org/wiki/Smartphone">smartphones</a>, <a href="https://en.wikipedia.org/wiki/Smartwatch">smartwatches</a>, <a href="https://en.wikipedia.org/wiki/Smart_TV">smart televisions</a> and <a href="https://en.wikipedia.org/wiki/Video_game_console">consoles</a>.<sup><a href="https://en.wikipedia.org/wiki/Web_browser#cite_note-1">[1]</a></sup> As of 2026, the most used browsers worldwide are <a href="https://en.wikipedia.org/wiki/Google_Chrome">Google Chrome</a> (~69% <a href="https://en.wikipedia.org/wiki/Market_share">market share</a>), <a href="https://en.wikipedia.org/wiki/Safari_(web_browser)">Safari</a> (~16%), <a href="https://en.wikipedia.org/wiki/Microsoft_Edge">Edge</a> (~5%), <a href="https://en.wikipedia.org/wiki/Firefox">Firefox</a> (~2%), <a href="https://en.wikipedia.org/wiki/Samsung_Browser">Samsung Browser</a> (~2%), and <a href="https://en.wikipedia.org/wiki/Opera_(web_browser)">Opera</a> (~2%).<sup><a href="https://en.wikipedia.org/wiki/Web_browser#cite_note-statcounter-2">[2]</a></sup><sup><a href="https://en.wikipedia.org/wiki/Web_browser#cite_note-cloudflare-3">[3]</a></sup> As of 2023, an estimated 5.4 billion people had used a browser.<sup><a href="https://en.wikipedia.org/wiki/Web_browser#cite_note-4">[4]</a></sup></p>
<!-- /wp:paragraph -->

<!-- wp:heading -->
<h2 class="wp-block-heading">Function</h2>
<!-- /wp:heading -->

<!-- wp:paragraph -->
<p><a href="https://en.wikipedia.org/w/index.php?title=Web_browser&amp;action=edit&amp;section=1"></a><video poster="https://upload.wikimedia.org/wikipedia/commons/thumb/c/c1/Web_browser_demo.webm/250px--Web_browser_demo.webm.jpg?utm_source=en.wikipedia.org&amp;utm_campaign=parser" controls="" preload="none" height="159" width="250"></video>Navigating to <a href="https://en.wikipedia.org/wiki/English_Wikipedia">English Wikipedia</a> using a web browser (<a href="https://en.wikipedia.org/wiki/Firefox">Firefox</a>)</p>
<!-- /wp:paragraph -->

<!-- wp:paragraph -->
<p>The purpose of a web browser is to fetch content and display it on the user's device.<sup><a href="https://en.wikipedia.org/wiki/Web_browser#cite_note-5">[5]</a></sup> This process begins when the user inputs a <a href="https://en.wikipedia.org/wiki/Uniform_Resource_Locator">Uniform Resource Locator</a> (URL), such as <em><code>https://en.wikipedia.org/</code></em>, into the browser's <a href="https://en.wikipedia.org/wiki/Address_bar">address bar</a>. Virtually all URLs on <a href="https://en.wikipedia.org/wiki/World_Wide_Web">the Web</a> start with either <em><code>http:</code></em> or <em><code>https:</code></em> which means they are retrieved with the <a href="https://en.wikipedia.org/wiki/HTTP">Hypertext Transfer Protocol</a> (HTTP). For <a href="https://en.wikipedia.org/wiki/HTTPS">secure mode</a> (HTTPS), the connection between the browser and <a href="https://en.wikipedia.org/wiki/Web_server">web server</a> is <a href="https://en.wikipedia.org/wiki/Encryption">encrypted</a>, providing a <a href="https://en.wikipedia.org/wiki/Communications_security">secure</a> and <a href="https://en.wikipedia.org/wiki/Information_privacy">private</a> data transfer.<sup><a href="https://en.wikipedia.org/wiki/Web_browser#cite_note-6">[6]</a></sup> For this reason, a web browser is often referred to as an HTTP client<sup><a href="https://en.wikipedia.org/wiki/Web_browser#cite_note-7">[7]</a></sup><sup><a href="https://en.wikipedia.org/wiki/Web_browser#cite_note-8">[8]</a></sup> or a <a href="https://en.wikipedia.org/wiki/User_agent">user agent</a>. Requisite materials, including text, <a href="https://en.wikipedia.org/wiki/Style_sheet_(web_development)">style sheets</a>, <a href="https://en.wikipedia.org/wiki/Images">images</a>, and other types of <a href="https://en.wikipedia.org/wiki/Website#Multimedia_and_interactive_content">multimedia</a>, are <a href="https://en.wikipedia.org/wiki/Downloaded">downloaded</a> from the server. Once the materials have been downloaded, the web browser's <a href="https://en.wikipedia.org/wiki/Browser_engine">engine</a> (also known as a layout engine or rendering engine) is responsible for converting those resources into an interactive visual representation of the page on the user's device.<sup><a href="https://en.wikipedia.org/wiki/Web_browser#cite_note-behindscene-9">[9]</a></sup> Modern web browsers also contain separate <a href="https://en.wikipedia.org/wiki/JavaScript_engine">JavaScript engines</a> which enable more complex interactive applications inside the browser.<sup><a href="https://en.wikipedia.org/wiki/Web_browser#cite_note-howBlinkWorks-10">[10]</a></sup> A web browser that does not render a <a href="https://en.wikipedia.org/wiki/Graphical_user_interface">graphical user interface</a> is known as a <a href="https://en.wikipedia.org/wiki/Headless_browser">headless browser</a>.</p>
<!-- /wp:paragraph -->

<!-- wp:paragraph -->
<p>Web pages usually contain <a href="https://en.wikipedia.org/wiki/Hyperlink">hyperlinks</a> to other pages and resources. Each link contains a URL, and when it is <a href="https://en.wikipedia.org/wiki/Point_and_click">clicked</a> or <a href="https://en.wikipedia.org/wiki/Touchscreen">tapped</a>, the browser navigates to the new resource. Most browsers use an internal <a href="https://en.wikipedia.org/wiki/Web_cache">cache</a> of web page resources to improve loading times for subsequent visits to the same page. The cache can store many items, such as large images, so they do not need to be downloaded from the server again. Cached items are usually only stored for as long as the web server stipulates in its HTTP response messages.<sup><a href="https://en.wikipedia.org/wiki/Web_browser#cite_note-11">[11]</a></sup><sup><a href="https://en.wikipedia.org/wiki/Web_browser#cite_note-12">[12]</a></sup></p>
<!-- /wp:paragraph -->

<!-- wp:paragraph -->
<p>A web browser is not the same thing as a <a href="https://en.wikipedia.org/wiki/Search_engine">search engine</a>, though the two are often confused.<sup><a href="https://en.wikipedia.org/wiki/Web_browser#cite_note-13">[13]</a></sup><sup><a href="https://en.wikipedia.org/wiki/Web_browser#cite_note-14">[14]</a></sup> A search engine is a website that provides <a href="https://en.wikipedia.org/wiki/Hyperlink">links</a> to other websites and allows users to search for specific resources using a textual <a href="https://en.wikipedia.org/wiki/Web_query">query</a>. However, web browsers are often used to access search engines, and most modern browsers allow users to access a default search engine directly by typing a query into the address bar.<sup><a href="https://en.wikipedia.org/wiki/Web_browser#cite_note-15">[15]</a></sup></p>
<!-- /wp:paragraph -->

<!-- wp:heading -->
<h2 class="wp-block-heading">History</h2>
<!-- /wp:heading -->

<!-- wp:paragraph -->
<p><a href="https://en.wikipedia.org/w/index.php?title=Web_browser&amp;action=edit&amp;section=2"></a></p>
<!-- /wp:paragraph -->

<!-- wp:paragraph -->
<p>Main article: <a href="https://en.wikipedia.org/wiki/History_of_the_web_browser">History of the web browser</a></p>
<!-- /wp:paragraph -->

<!-- wp:paragraph -->
<p>The first web browser, called <a href="https://en.wikipedia.org/wiki/WorldWideWeb">WorldWideWeb</a>, was created in 1990 by Sir <a href="https://en.wikipedia.org/wiki/Tim_Berners-Lee">Tim Berners-Lee</a>.<sup><a href="https://en.wikipedia.org/wiki/Web_browser#cite_note-16">[16]</a></sup><sup><a href="https://en.wikipedia.org/wiki/Web_browser#cite_note-17">[17]</a></sup> He then recruited <a href="https://en.wikipedia.org/wiki/Nicola_Pellow">Nicola Pellow</a> to write the <a href="https://en.wikipedia.org/wiki/Line_Mode_Browser">Line Mode Browser</a>, which displayed web pages on <a href="https://en.wikipedia.org/wiki/Dumb_terminals">dumb terminals</a>.<sup><a href="https://en.wikipedia.org/wiki/Web_browser#cite_note-:5-18">[18]</a></sup> The <a href="https://en.wikipedia.org/wiki/Mosaic_(web_browser)">Mosaic</a> web browser was released in April 1993, and was later credited as the first web browser to find mainstream popularity.<sup><a href="https://en.wikipedia.org/wiki/Web_browser#cite_note-19">[19]</a></sup><sup><a href="https://en.wikipedia.org/wiki/Web_browser#cite_note-bloomberg-20">[20]</a></sup> Its innovative <a href="https://en.wikipedia.org/wiki/Graphical_user_interface">graphical user interface</a> made the <a href="https://en.wikipedia.org/wiki/World_Wide_Web">World Wide Web</a> easy to navigate and thus more accessible to the average person. This, in turn, sparked the Internet boom of the 1990s, when the Web grew at a very rapid rate.<sup><a href="https://en.wikipedia.org/wiki/Web_browser#cite_note-bloomberg-20">[20]</a></sup> The lead developers of Mosaic then founded the <a href="https://en.wikipedia.org/wiki/Netscape">Netscape</a> corporation, which released the Mosaic-influenced <a href="https://en.wikipedia.org/wiki/Netscape_Navigator">Netscape Navigator</a> in 1994. Navigator quickly became the <a href="https://en.wikipedia.org/wiki/Usage_share_of_web_browsers#Older_reports_(pre-2000)">most popular</a> browser.<sup><a href="https://en.wikipedia.org/wiki/Web_browser#cite_note-21">[21]</a></sup></p>
<!-- /wp:paragraph -->

<!-- wp:paragraph -->
<p><a href="https://en.wikipedia.org/wiki/Microsoft">Microsoft</a> debuted <a href="https://en.wikipedia.org/wiki/Internet_Explorer">Internet Explorer</a> in 1995, leading to a <a href="https://en.wikipedia.org/wiki/Browser_war">browser war</a> with Netscape. Within a few years, Microsoft gained a dominant position in the browser market for two reasons: it bundled Internet Explorer with its popular <a href="https://en.wikipedia.org/wiki/Microsoft_Windows">Windows</a> <a href="https://en.wikipedia.org/wiki/Operating_system">operating system</a> and did so as <a href="https://en.wikipedia.org/wiki/Freeware">freeware</a> with no restrictions on usage. The market share of Internet Explorer peaked at over 95% in the early 2000s.<sup><a href="https://en.wikipedia.org/wiki/Web_browser#cite_note-searchenginejournal.com-22">[22]</a></sup> In 1998, Netscape launched what would become the <a href="https://en.wikipedia.org/wiki/Mozilla_Foundation">Mozilla Foundation</a> to create a new browser using the <a href="https://en.wikipedia.org/wiki/Open-source_software">open-source software</a> model. This work evolved into the <a href="https://en.wikipedia.org/wiki/Firefox">Firefox</a> browser, first released by Mozilla in 2004. Firefox's market share peaked at 32% in 2010.<sup><a href="https://en.wikipedia.org/wiki/Web_browser#cite_note-23">[23]</a></sup> <a href="https://en.wikipedia.org/wiki/Apple_Inc.">Apple</a> released its <a href="https://en.wikipedia.org/wiki/Safari_(web_browser)">Safari</a> browser in 2003; it remains the dominant browser on Apple devices, though it did not become popular elsewhere.<sup><a href="https://en.wikipedia.org/wiki/Web_browser#cite_note-browsershare-24">[24]</a></sup></p>
<!-- /wp:paragraph -->

<!-- wp:paragraph -->
<p><a href="https://en.wikipedia.org/wiki/Google">Google</a> debuted its <a href="https://en.wikipedia.org/wiki/Google_Chrome">Chrome</a> browser in 2008, which steadily took market share from Internet Explorer and became the most popular browser in 2012.<sup><a href="https://en.wikipedia.org/wiki/Web_browser#cite_note-25">[25]</a></sup><sup><a href="https://en.wikipedia.org/wiki/Web_browser#cite_note-26">[26]</a></sup> Chrome has <a href="https://en.wikipedia.org/wiki/Usage_share_of_web_browsers">remained dominant</a> ever since.<sup><a href="https://en.wikipedia.org/wiki/Web_browser#cite_note-statcounter-2">[2]</a></sup> In 2015, Microsoft replaced Internet Explorer with <a href="https://en.wikipedia.org/wiki/Microsoft_Edge_Legacy">Edge [Legacy]</a> for the <a href="https://en.wikipedia.org/wiki/Windows_10">Windows 10</a> release.<sup><a href="https://en.wikipedia.org/wiki/Web_browser#cite_note-27">[27]</a></sup> In 2020, this legacy version was replaced by a new <a href="https://en.wikipedia.org/wiki/Chromium_(web_browser)">Chromium</a>-based version of <a href="https://en.wikipedia.org/wiki/Microsoft_Edge">Edge</a>.</p>
<!-- /wp:paragraph -->

<!-- wp:paragraph -->
<p>Since the early 2000s, browsers have greatly expanded their <a href="https://en.wikipedia.org/wiki/HTML">HTML</a>, <a href="https://en.wikipedia.org/wiki/CSS">CSS</a>, <a href="https://en.wikipedia.org/wiki/JavaScript">JavaScript</a>, and <a href="https://en.wikipedia.org/wiki/Multimedia">multimedia</a> capabilities. One reason has been to enable more sophisticated websites, such as <a href="https://en.wikipedia.org/wiki/Web_application">web apps</a>. Another factor is the significant increase of <a href="https://en.wikipedia.org/wiki/Broadband">broadband</a> connectivity in <a href="https://en.wikipedia.org/wiki/List_of_sovereign_states_by_number_of_broadband_Internet_subscriptions">many parts</a> of the world, enabling people to access data-intensive content, such as <a href="https://en.wikipedia.org/wiki/Streaming_media">streaming</a> <a href="https://en.wikipedia.org/wiki/High-definition_video">HD video</a> on <a href="https://en.wikipedia.org/wiki/YouTube">YouTube</a>, that was not possible during the era of <a href="https://en.wikipedia.org/wiki/Dial-up_Internet_access">dial-up modems</a>.<sup><a href="https://en.wikipedia.org/wiki/Web_browser#cite_note-28">[28]</a></sup></p>
<!-- /wp:paragraph -->

<!-- wp:paragraph -->
<p>Starting in the mid-2020s, browsers with integrated <a href="https://en.wikipedia.org/wiki/Artificial_intelligence">artificial intelligence</a> (AI) capabilities, known as <a href="https://en.wikipedia.org/wiki/AI_browser">AI browsers</a>, have become increasingly common. This includes both new entrants to the browser market, such as <a href="https://en.wikipedia.org/wiki/Comet_(browser)">Perplexity Comet</a> and <a href="https://en.wikipedia.org/wiki/ChatGPT_Atlas">ChatGPT Atlas</a>, and established browsers that added AI features, such as Chrome with the <a href="https://en.wikipedia.org/wiki/Gemini_(chatbot)">Gemini</a> <a href="https://en.wikipedia.org/wiki/Chatbot">chatbot</a> and Edge with the <a href="https://en.wikipedia.org/wiki/Microsoft_Copilot">Copilot</a> chatbot.<sup><a href="https://en.wikipedia.org/wiki/Web_browser#cite_note-29">[29]</a></sup><sup><a href="https://en.wikipedia.org/wiki/Web_browser#cite_note-30">[30]</a></sup></p>
<!-- /wp:paragraph -->

<!-- wp:heading -->
<h2 class="wp-block-heading">Features</h2>
<!-- /wp:heading -->

<!-- wp:paragraph -->
<p><a href="https://en.wikipedia.org/w/index.php?title=Web_browser&amp;action=edit&amp;section=3"></a></p>
<!-- /wp:paragraph -->

<!-- wp:paragraph -->
<p>The most popular browsers share many <a href="https://en.wikipedia.org/wiki/Software_feature">features</a>. They automatically log users' <a href="https://en.wikipedia.org/wiki/Web_browsing_history">browsing history</a>, unless the users turn off their browsing history or use the non-logging <a href="https://en.wikipedia.org/wiki/Private_browsing">private mode</a>. They also allow users to set <a href="https://en.wikipedia.org/wiki/Bookmark_(digital)">bookmarks</a>, customize the browser with <a href="https://en.wikipedia.org/wiki/Browser_extension">extensions</a>, and <a href="https://en.wikipedia.org/wiki/Download_manager">manage their downloads</a><sup><a href="https://en.wikipedia.org/wiki/Web_browser#cite_note-31">[31]</a></sup> and <a href="https://en.wikipedia.org/wiki/Password">passwords</a>.<sup><a href="https://en.wikipedia.org/wiki/Web_browser#cite_note-32">[32]</a></sup> Some provide a sync service<sup><a href="https://en.wikipedia.org/wiki/Web_browser#cite_note-33">[33]</a></sup> and <a href="https://en.wikipedia.org/wiki/Web_accessibility">web accessibility</a> features.<sup><a href="https://en.wikipedia.org/wiki/Web_browser#cite_note-34">[34]</a></sup></p>
<!-- /wp:paragraph -->

<!-- wp:image {"width":"500px","height":"auto","aspectRatio":"1.6666666666666667","linkDestination":"custom"} -->
<figure class="wp-block-image is-resized"><a class="mw-file-description pcs-widen-image-ancestor" href="https://en.wikipedia.org/wiki/File:Chromium_(web_browser).png"><img src="https://upload.wikimedia.org/wikipedia/commons/thumb/1/13/Chromium_%28web_browser%29.png/500px-Chromium_%28web_browser%29.png?utm_source=en.wikipedia.org&amp;utm_campaign=parser&amp;utm_content=thumbnail" alt="" style="aspect-ratio:1.6666666666666667;width:500px;height:auto" /></a><figcaption class="wp-element-caption">Traditional browser arrangement has <a href="https://en.wikipedia.org/wiki/User_interface">user interface</a> features above page content.</figcaption></figure>
<!-- /wp:image -->

<!-- wp:paragraph -->
<p>Common <a href="https://en.wikipedia.org/wiki/User_interface">user interface</a> (UI) features:</p>
<!-- /wp:paragraph -->

<!-- wp:list -->
<ul class="wp-block-list"><!-- wp:list-item -->
<li>Allowing the user to have multiple <a href="https://en.wikipedia.org/wiki/Web_page">pages</a> open at the same time, either in different <a href="https://en.wikipedia.org/wiki/Window_(computing)">windows</a> or in different <a href="https://en.wikipedia.org/wiki/Tab_(interface)">tabs</a> of the same window.</li>
<!-- /wp:list-item -->

<!-- wp:list-item -->
<li><em>Back</em> and <em>forward</em> buttons to go back to the previous page visited or forward to the next one.</li>
<!-- /wp:list-item -->

<!-- wp:list-item -->
<li>A
